# 🎓 Student Placement Prediction

This project predicts whether a student will be placed based on skills and performance.

## 🚀 Features
- Machine Learning model (Logistic Regression)
- Streamlit web app
- Real-time prediction

## 🛠 Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit

## 📊 Input Features
- CGPA
- Internships
- Projects
- Coding Skills
- Communication Skills
- Aptitude Score
- Soft Skills
- Certifications
- Backlogs

## 🔗 Live App
[Click here to open app](https://placement-app-ardra.streamlit.app)

## 💡 Description
This app uses a trained machine learning model to predict placement outcomes based on student performance data.
